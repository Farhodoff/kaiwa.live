# 🎌 kaiwa.live Japanese Curriculum & Localization Guidelines

## Lesson Principles
1. **100% Fluent Uzbek:** Explanations must be written in natural, academic Uzbek (avoiding literal Russian calques).
2. **Standardized Romaji:** Use Hepburn Romanization with clear macrons (`ō`, `ū`).
3. **Furigana:** All Kanji above beginner level must use bracketed furigana `[漢字|かんじ]` notation.
4. **Cultural Context:** Explain nuanced nuances (e.g. *uchi* vs *soto*, keigo honorifics) clearly with everyday examples.
